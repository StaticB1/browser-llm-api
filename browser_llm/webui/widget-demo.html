Browser LLM widget

A chat bubble on any page

This is an ordinary web page. One script tag put the bubble in the corner, and it answers from the signed-in browser session running on your own machine.

The whole integration

The widget finds the server from its own script URL, so the page can sit on any origin or port. Everything else is a data-* attribute.

<script src="http://localhost:8081/widget.js"
        data-title="Ask AI"
        data-greeting="Hi. Ask me anything."
        data-suggestions="Explain what an API key is|Write a haiku about Seoul in autumn|Turn this into a checklist: pack, book, confirm"></script>

Drive it from the page

BrowserLLMWidget.ask() sends a turn and resolves with the answer. Calls made while one is streaming wait their turn.

Restyle it live

config() changes the look without reloading; the thread is kept.

Events

on("ready" | "open" | "close" | "message" | "error", fn), newest first.

Browser LLM

The chat bubble, embedded

An ordinary web page. One script tag put the bubble in the corner, and it answers from the logged-in browser session running on your own machine.

The whole integration

<script src="http://localhost:8081/widget.js"
        data-title="Ask AI"
        data-greeting="Hi. Ask me anything."></script>

The widget finds the API base in its own script URL, so this page can sit on any origin or port. Attachments, paste and drag-drop go in through the plus button for vision questions. Everything else is a data-* attribute: provider, title, accent, position, greeting, system, theme, persist, open.

Things to try

  • Ask for code. It comes back as a card you can copy in one click.
  • Switch model in the header, gemini or chatgpt.
  • Reload the page. The thread is still there, and the pencil clears it.
  • Send a long question, then press stop while it streams.
  • Press Esc to close.

From the console: BrowserLLMWidget.open(), .close(), .reset(), .config({accent:'#0D0D0D'}).
